# Change Log

All notable changes to the Code Project Tracker extension will be documented in this file.

## 0.0.1 - 2026-11-01

### Added
- Initial release of the Code Project Tracker system.
- Implemented dual-view workspace mechanics supporting both the vertical Sidebar Panel view and a full-screen Main Editor Kanban dashboard tab.
- Added an inline text form input interface for adding tasks to prevent environment freezing.
- Implemented file system synchronization writing states directly to a local, human-readable .tracker-tasks.json configuration file.
- Configured a message pipeline enabling a one-click dashboard launch sequence directly from inside the sidebar panel.
- Adopted native VS Code $(checklist) Codicons for optimized sidebar activity bar styling.
